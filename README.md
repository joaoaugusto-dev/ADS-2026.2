## Sobre este repositório

Este repositório reúne tudo que desenvolvo ao longo do **segundo semestre de 2026** do curso de Análise e Desenvolvimento de Sistemas na UNIFEOB: testes, exercícios, acompanhamento com o professor em aula e projetos práticos. O conteúdo é organizado por disciplina, e cada disciplina é subdividida por aula, com data e tema.
